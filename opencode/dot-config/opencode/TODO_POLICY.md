# Todo Management

For any task with three or more distinct steps, create a todo list before beginning work.

Keep exactly one todo item in progress. Update the list immediately when work completes, the scope changes, or follow-up work is discovered. Do not mark an item complete until its required verification has passed.

For smaller tasks, use a todo list when it improves execution clarity or when the user asks for one.

Never read, edit, search for, or expose the contents of `.env` files or files whose names begin with `.env.`, except `.env.sample` and `.env.example`, which may be read.
